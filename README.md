Amazon Phone Products – Data Analysis

Project Overview

This project focuses on analyzing Amazon mobile phone products to explore product performance, pricing patterns, customer ratings, reviews, and available offers.

The project uses Python for data cleaning and exploratory data analysis, followed by Microsoft Power BI for data transformation, measures creation, and interactive dashboard development.

Tools & Technologies

* Python: Data Cleaning and Exploratory Data Analysis (EDA).
* Pandas: Data manipulation and analysis.
* Microsoft Power BI: Data modeling and visualization.
* Power Query: Data transformation and preparation.
* Power BI Measures: Calculations and analytical metrics.

Project Workflow

1. Data Cleaning & Analysis – Python

* Importing and exploring the dataset.
* Handling missing and inconsistent data.
* Cleaning and preparing the dataset.
* Performing Exploratory Data Analysis (EDA).

2. Data Transformation – Power BI

* Importing the cleaned dataset into Power BI.
* Using Power Query for additional data transformations.
* Preparing data for analysis and visualization.

3. Dashboard Development – Power BI

* Creating analytical measures.
* Designing interactive visualizations.
* Building a dashboard to explore product and pricing insights.

Project Deliverable

An interactive Power BI dashboard providing insights into Amazon mobile phone products and their key performance indicators.

Project Status

Dashboard Development Completed.
